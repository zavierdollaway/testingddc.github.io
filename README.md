# Dexterous Design Challenge Website Prototype

This is a static prototype for the Dexterous Design Challenge.

## Files
- index.html — website structure and content
- styles.css — responsive styling
- script.js — small interactions

## How to view
Double-click `index.html` to open it in a browser.

## What to replace
Search the HTML for placeholder content and replace:
- DDC 2027 challenge description
- official eligibility/rules
- registration links
- actual module links
- previous competition results
- real project photos/videos
- guidebook and resource links
- official organization/contact information

## Recommended next development
1. Connect registration buttons to official forms/database.
2. Add a real DDC domain owned by the organization.
3. Move project files to organization-owned storage.
4. Add a team/participant portal if needed.
5. Add an admin system for managing registrations and results.

## Admin editing
Click **Admin** in the footer (or open `index.html#admin`) and enter the password. Click any text to edit it, use the buttons on cards/sections to duplicate, delete or reorder, and use the bottom bar to save, add sections, or **Download site**.
Edits save in your browser only. To publish them, click **Download site** and replace `index.html` with the downloaded file.
